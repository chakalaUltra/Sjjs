# Kaiser – Viber Bot powered by Groq AI

A professional Viber bot named **Kaiser** that forwards every user message to the **Groq AI** API and replies with the generated answer.

## Features

- Real‑time chat on Viber.
- Uses Groq’s LLM (default: `llama3-70b-8192`).
- Stateless – each message is processed independently.
- Simple configuration via `.env`.

## Prerequisites

- Node.js >= 18
- A **Viber Public Account** with a bot token.
- A **Groq API key** (sign up at https://groq.com).
